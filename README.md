# FLGB Conseils

Site vitrine statique de FLGB Conseils, consacré à la sécurité, à la sûreté et à la cybersécurité des TPE/PME.

## Publication

- Branche de production : `main`
- URL principale : https://flgb-conseils.netlify.app/
- Les URL canoniques et le sitemap utilisent ce domaine.

## Pages principales

- `index.html` : accueil
- `services.html` : services
- `offres.html` : offres et tarifs de référence
- `apropos.html` : présentation
- `contact.html` : formulaire de contact
- `audit-flash.html` : Diagnostic Cyber Express
- `kit-cyber.html` : offre Kit Cyber
- `capture.html` : collecte d’adresse pour le guide
- `merci-capture.html` : téléchargement du guide

## Points de contrôle avant publication

1. Vérifier que les tarifs correspondent à `offres.html`.
2. Tester les formulaires et tous les téléchargements.
3. Contrôler l’affichage mobile et l’encodage UTF-8.
4. Vérifier les liens internes, `robots.txt` et `sitemap.xml`.
5. Ne jamais déposer de données de prospects, identifiants ou secrets dans ce dépôt public.

## Données personnelles

Le dépôt est public. Les fichiers contenant des données personnelles, listes de prospection ou exports de formulaires ne doivent jamais y être ajoutés. La suppression d’un fichier dans un commit ne le supprime pas automatiquement de l’historique Git.
